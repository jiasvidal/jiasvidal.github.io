# Aged Ticket Reporter demo kit

Start with BUILD-GUIDE.md. Upload Aged-Ticket-Demo.xlsx to your own OneDrive for Business or SharePoint, then build the flow in Power Automate using a Microsoft 365 work or school account with the required connector access.

This kit contains fictional data and a guide, not an importable Power Automate flow. Configure your own connections and send test emails only to your own mailbox. Each manual run sends three reports with this workbook. There is no send-history tracking.

Expected results: Alex DEMO-1001–1004; Morgan DEMO-1005–1008; Sam no report; Taylor DEMO-1009–1012. Each report has four tickets. All supplied rows are routed by owner; no age cutoff or status filter is applied.
